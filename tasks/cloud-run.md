# 保存到 Codex 原生云端定时任务的指令

每天北京时间08:30开始，执行“A股每日低估值选股与交易计划”。必须在已发布的Codex Cloud研究环境中独立运行。沿用账号默认模型。读取本仓库tasks/research.md并完整遵守其十部分规则；读取config/cloud-task.json了解时间和通知偏好。

使用公开可验证数据，不调用券商接口或真实买卖。独立更新交易日历、行情、公告和财务。先评估长期经营质量及至少两种估值，再分析技术与条件买点。主板股票最多五只，只有A类给条件交易计划；关键数据不可靠时不给候选，明确数据不足。休市日仅发送休市提示。

运行前读取GitHub仓库i-meteor-shower/ashare-daily-research的最新main。检查之前data/runs/中的pending/unknown回执并明确待核查，不重发旧摘要。普通未完成观察窗口继续追踪，未验证触发不得记成交。

在临时工作目录生成完整Markdown报告和结构化result.json，使用docs/result-contract.md的格式。将可核验采集快照、估值输入及指标口径保存到data/evidence/日期/版本/，所有价格注明实际日期。披露覆盖数，覆盖不足不能声称全市场筛选。按research.md五部分格式输出完整报告，飞书仅推送操作摘要。

先运行 `python scripts/workflow.py validate 临时结果.json`，校验不通过就修正或降级为数据不足，不能用修改校验器的方式凑推荐。然后运行 `python scripts/workflow.py archive 临时结果.json 临时报告.md`，记下返回run目录。该命令保留原报告和新版本、追加历史并生成摘要。

将本次报告、原始研究结果、来源证据、历史记录及prepared回执提交并推送至main；禁止force push。push冲突时重新获取最新历史并追加保留所有版本，不覆盖其他运行。随后运行 `python scripts/workflow.py send 返回的run目录`。该命令先把pending回执提交并推送，再发飞书，最后保存业务回执；如无法持久保存pending状态则不发送。

FEISHU_WEBHOOK_URL仅从云端秘密配置读取，不打印、不写入仓库或公开报告。飞书只发送摘要，内容含日期、基准日、策略、候选条件、风险、数据状态及完整报告链接。发送不确定时记unknown并停止自动重发；发送失败或历史保存失败需明确报告，不声称任务成功。

结束时给出报告链接、数据状态、实际覆盖情况及推送状态。首次完整云端手动试运行未通过前不得启用日程。禁止将本任务改成依赖本机的日程，禁止创建第三方调度替代。
